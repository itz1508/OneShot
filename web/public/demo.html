ONE SHOT / DISPLAY CONTRACT
Why the screen changes.
Research shows queries and linked source findings. Build Discovery reveals the physical file map. Planning presents decisions and action contracts. Scanner displays findings. Build shows file actions. Verification shows actual check records. The final screen shows artifacts and receipts.
Agent mode streams provider-authored text for Research, Build Discovery and a provisional Planning draft. It does not execute Build. The read-only producer observes local files; the tour is sample data.
Correlated operations, source lines, errors, and receipts remain inspectable. Animations only follow received events. Private model reasoning is never displayed.
