# GAP-0006 — `@oneshot/rsm-client` standalone tsc not reproducible

- **status**: closed
- **origin**: verified gap (follow-up to GAP-0001, closing-gap run 2026-04-10)
- **gap**: GAP-0001 added `packages/rsm-client/tsconfig.json`, but the
  package declared no `typescript` dependency, so `pnpm exec tsc` from
  `packages/rsm-client` resolved binaries only through workspace siblings —
  it worked incidentally and broke (exit 127-equivalent, `Command "tsc" not
  found`) after a workspace `pnpm install` re-linked bins.
- **evidence**:
  - pre: `cd packages/rsm-client && pnpm exec tsc -p tsconfig.json` →
    `ERR_PNPM_RECURSIVE_EXEC_FIRST_FAIL Command "tsc" not found`
  - post: exit 0 after adding local devDependency.
- **required_ending_behavior**: the GAP-0001 validation command passes from
  the package directory regardless of workspace bin-linking state.
