# GAP-0007 — UI could not read daemon responses (missing CORS)

- **status**: closed
- **origin**: verified gap (discovered while starting the UI, 2026-04-10)
- **gap**: the Next.js UI runs on `http://localhost:3000` and constructs
  `new RsmClient()` with base `http://127.0.0.1:8787` (direct cross-origin
  fetches), but `create_app()` installed no CORS middleware — no
  `Access-Control-Allow-Origin` header on any response, so every browser
  read from the UI fails the same-origin policy while the daemon itself
  stays green. Never caught because the HTTP contract tests use FastAPI
  `TestClient` (no browser) and the Playwright specs have never executed.
- **evidence**:
  - pre: live probe `GET /healthz` with `Origin: http://localhost:3000` →
    no `access-control-allow-origin` header
  - post: same probe → `ACAO: http://localhost:3000`; foreign origin gets
    no header
- **required_ending_behavior**: live daemon serves ACAO for the two dev
  origins (localhost:3000 / 127.0.0.1:3000), not for foreign origins;
  preflight OPTIONS for JSON POSTs succeeds; contract locked by tests.

## Timeline

- **2026-04-10 detected** — healthz OK, UI page 200, but CORS probe empty
