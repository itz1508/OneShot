## Architecture (authoritative owners)

- **Transport**: [`systems/transport.py`](D:\OneShot\systems\transport.py) — FastAPI + CORS + OpenTelemetry FastAPI instrumentor. Unprefixed routes. Health must check SQLite + blob root, not just process up.
- **Contract**: [`systems/contract.py`](D:\OneShot\systems\contract.py) — Pydantic v2 `extra="forbid"`. Summarize artifact is **exactly** `{"summary": "Non-empty summary text"}`. Also: Conversation, Message, Artifact, Job, Run, Event, Trace, API error, Draft.
- **Store**: [`systems/store.py`](D:\OneShot\systems\store.py) — SQLite transactions. Conversations, messages, artifacts, jobs, runs, drafts, `conversation_events` with **atomic sequence**, Trace records. No in-memory durability.
- **Blobs**: [`capabilities/blobstore.py`](D:\OneShot\capabilities\blobstore.py) — SHA-256 content-addressed files under `ONESHOT_DATA_DIR/blobs`. Atomic write + hash verify. Never expose physical paths as filenames.
- **Runs vs Jobs**: **Run** owns model/capability execution and its string result. **Job** owns conversation action dispatch, artifact creation, and completion. A Summarize Job may invoke a Run; they must not share one HTTP interface. Every mutating or blob read verifies **conversation ownership** even when a Run id is global.
- **Coder**: [`capabilities/coder.py`](D:\OneShot\capabilities\coder.py) — `fake` deterministic provider for all automated tests; `real` is a narrow HTTP/SDK adapter behind `ONESHOT_MODEL_ENDPOINT` / `ONESHOT_MODEL_NAME`. No Pydantic AI. Fake success does **not** count as production model integration.
- **Jobs**: one executor (e.g. `systems/jobs.py`). Actions: `scan`, `summarize`, `rewrite`, `review`, `fix`, `validate`. Persist artifact **before** `job.completed`.
- **Events / replay / Trace**: durable event names from the spec, including **draft.created**. Each save is a **new immutable draft artifact**; replay reconstructs the revision chain. Do not re-run models or regenerate blobs. OTel spans are **not** OneShot Trace.
- **Frontend client**: [`frontend/src/api/oneshot.ts`](D:\OneShot\frontend\src\api\oneshot.ts) talks to `/api...` (Vite/nginx strip `/api`). Types from live `openapi.json`. No `contract_pending`.

Dev proxy: browser `/api/conversations` → FastAPI `/conversations`. Compose nginx same mapping. Bind UI to `127.0.0.1:8080` in Docker.

## HTTP surface (implement for real)

**Canonical HTTP contract (Conversation-scoped; document in OpenAPI before frontend work).** Global `/jobs` and `/artifacts/{id}/blob` are **not** used.

- `GET /health`
- `POST /conversations`, `GET /conversations/{conversation_id}`
- `POST /conversations/{conversation_id}/messages`
- `POST /conversations/{conversation_id}/sources` — pasted body (`text/plain` → `source.txt`, `text/markdown` → `source.md`)
- `POST /conversations/{conversation_id}/artifacts` — multipart upload; preserve safe logical name + original bytes
- `GET /conversations/{conversation_id}/artifacts/{artifact_id}`
- `GET /conversations/{conversation_id}/artifacts/{artifact_id}/blob`
- `POST /conversations/{conversation_id}/jobs`
- `GET /conversations/{conversation_id}/jobs/{job_id}`
- `POST /runs`, `GET /runs/{run_id}`, `GET /runs/{run_id}/result`, `GET /runs/{run_id}/events` (body/query includes `conversation_id`; ownership checked)
- `GET /conversations/{conversation_id}/events`, `POST /conversations/{conversation_id}/replay`
- `POST /conversations/{conversation_id}/drafts`
- `GET /conversations/{conversation_id}/drafts/{draft_artifact_id}`
- Optional SSE for job/run progress if used by the UI; otherwise poll status honestly

Reject requests whose resource `conversation_id` does not match the path (or the Run's owning conversation).

### Draft-save contract

`POST /conversations/{conversation_id}/drafts` fields:

- `source_artifact_id` — original (immutable)
- `source_sha256` — provenance of that original; mismatch is a **400**, not a concurrent-edit conflict
- `expected_draft_revision` — current head draft artifact id (or null for first save); **stale value → HTTP 409**
- body content — bytes of the new draft

Each successful save creates a **new** `draft_artifact_id` (immutable revision). Do **not** mutate the original artifact and do **not** overwrite an earlier draft blob/row. Persist `draft.created` with the new id so replay/restart reconstructs the full revision list.

Ingest **does not** summarize. Oversized / unsupported / empty-per-policy fail with typed API errors.
